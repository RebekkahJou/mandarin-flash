# Product spec (as written by the project owner)

The build plan's decisions refine this spec:
- Pinyin is always stored. Zhuyin is a display setting.
- A word's frequency tier is shared across all lists.
- Fonts are open-licensed (OFL) rather than strictly public domain.

---

What do I want in my flashcards app?
The app is for learning traditional Chinese, as spoken in Taiwan.For the flashcards, which is the primary function, each flashcard shows a character. The user touches the screen to reveal both the pinyin and the English.Have a button to show in a sentenceCan do phrases as well as standalone characters.Characters show with varying frequency in 'practice sets' based on which object the characters are assigned to. Practice sets draw from objects of 'high incidence' (60%), 'memory reinforcement ' (30%,) 'retention' (10%) to make practice sets of 20/40/60/80 words (default 40).
The flashcard Chinese characters randomly change between 3-4 public domain fonts. They do not rotate English fonts (font-family: sans-serif is fine).There is a Button for 'missed' (the flashcard reappears soon thereafter), for 'gotten' (goes to end), for 'learned' (downgrades frequency)Set ends when user: -selects End-All words learned-prompt to end shows after all words gotten, but use can either end or keep goingA timer tracks how long the user takes to finish the set from start to hitting End, and also how long it takes the user to get through the full deck without mistakes, if different from how long it takes them to hit End.
Users can have multiple profiles (for parents of kids also learning) (maybe not in MVP, but should allow this soon after). Each profile can have multiple word lists ( different purposes, such as verbs, adjectives, nouns, most common basic vocab). Users start with default word lists nouns, verbs, adjectives, phrases, focus vocabulary, general vocabulary.
New words are added to general vocabulary by default, but can be added to multiple lists (should select with a modal which lists to add it to). If a word that has no verb meaning is added to the verb list, a warning pops up to confirm (and same with other parts of speech).Users can manually enter characters to add them to the word list. Autopopulates meaning from most common 3 meanings if user does not manually enter meaning, giving user chance to change selected meanings (exception, word lists labeled with parts of grammar, 'noun' etc, use first 3 meanings of that word type instead of any first 3 meanings).Users can enter a preset word list as a csv file. If any word does not include a translation, system finds it. System also allows exporting profile word sets as csv (character+meaning+pinyin) making upgrading from a profile to new user easier.Characters can be added multiple times to word lists, pops up a notification if so for each selected word list if a word is already in it. When adding words from a csv file, characters are not duplicated if they are already in the list (user has to manually add them to have duplicates). User has ability to change definition for different word lists. Every character, if entered as simplified Chinese, auto converts to Traditional.If a character has a simplified version, an optional setting shows the simplified Chinese character in a corner, or shows a button that opens a modal with the simplified Chinese.Future features may include a button that will generate a simple sentence containing the word or phrase, using AI.
Future feature: User profile games: Challenge other users to various competitive minigames (fastest progression through shared words, etc)
Word lists object interface: contains length of word list (optional), adding new words method (recalculates length and adds word to word list), removing words method (recalculates length and removes word), Words array
Words object interface: character (traditional), pinyin, definitions, character (simplified) (optional)
All word lists are types of WordList
App should be standalone within each phone, no shared backend needed. (this will limit online games with other users-- future microservice may upload word lists to a shared server for playing with other users of similar levels/friend groups)
